# Quiz en images (Vue 3)

**Auteur :** DhiaEddine Rezgani — L2DSI1

Quiz de 5 questions illustrées (thème : formes géométriques), 3 choix par question, score et barre de progression. Une seule page : `src/App.vue` (Composition API, sans Vue Router, sans serveur).

## Commandes
```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## Contenu du dépôt
- `src/App.vue` : tableau des questions, logique, template et CSS
- `public/images/` : les 5 images (SVG)
- `captures/` : captures d'écran (question, bonne réponse, mauvaise réponse, écran final)
- `compte-rendu/compte-rendu.md` : compte rendu du travail
